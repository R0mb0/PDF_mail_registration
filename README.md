# PDF_mail_registration

[![Codacy Badge](https://app.codacy.com/project/badge/Grade/a23bdb03b9174bfd8d9094ad2e3c36af)](https://app.codacy.com/gh/R0mb0/PDF_mail_registration/dashboard?utm_source=gh&utm_medium=referral&utm_content=&utm_campaign=Badge_grade)

Privacy-first event registration without a server: participants fill a LaTeX-generated PDF form and email it back, then a local Python app (with a small GUI) parses, deduplicates, and exports the data to CSV, Excel, SQLite, and plain text — all processing stays on your machine.
